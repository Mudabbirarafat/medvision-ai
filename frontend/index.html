Model Architecture
Input Image (chest X-ray JPEG/PNG)
        │
  [scripts/preprocess_chexpert.py]
  → Resize + normalize → processed CSV
        │
  [training/dataset.py]
  → CheXpertDataset: load JPEG → tensor
  → ImageNet normalization (mean/std)
  → Train: augment (flip, rotate, jitter)
        │
  [training/train.py]
  ┌──────────────────────────────────────┐
  │  ResNet18 (ImageNet pretrained)      │
  │  → Remove FC layer                  │
  │  → feature vector (512-dim)         │
  │  → Linear(512 → 256) + ReLU + Drop  │
  │  → Linear(256 → 6) [no sigmoid]     │
  └──────────────────────────────────────┘
        │  logits (6,)
  BCEWithLogitsLoss(pos_weight=...)
  AdamW + CosineAnnealingLR
        │
  models/chexpert_model.pth
        │
  [model_service/main.py]  FastAPI :8001
  → sigmoid(logits) → probabilities
  → threshold (0.4) → positive/negative
  → report_generator.py → NL report
  → qa_engine.py → Q&A
        │
  [backend/main.py]  FastAPI :8000
        │
  [frontend/index.html]  Browser

Quick Commands
# 1. Install
pip install -r requirements.txt

# 2a. Download real CheXpert:
# https://stanfordmlgroup.github.io/competitions/chexpert/

# 2b. OR create test sample:
python scripts/download_sample.py

# 3. Preprocess
python scripts/preprocess_chexpert.py \
  --max_samples 5000 --uncertainty zeros

# 4. Train (CPU, ~2–3 h for 5000 samples)
python training/train.py \
  --max_samples 5000 --epochs 10

# 5. Evaluate
python training/evaluate.py \
  --model models/chexpert_model.pth

# 6. Start model service (terminal 1)
cd model_service
uvicorn main:app --port 8001

# 7. Start backend (terminal 2)
cd backend
uvicorn main:app --port 8000

# 8. Open frontend
open frontend/index.html
